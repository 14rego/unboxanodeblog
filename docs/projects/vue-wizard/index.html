Vue Wizard

A few wizard helper views

The Big Idea

We have several processes where our call center users go through a series of form steps to complete a task. This project includes a full Road Map that shows the user’s progress, a more succinct Progress Bar, and a Form Step container that allows navigation and expanding/collapsing the individual steps.

Stack:

  • Vue
  • Typescript
  • Lucide Icons
  • TailwindCSS
  • Git Repo

Development

No Brainer

Making a set of wizard components was a necessity for some of our longer forms, like when our call center employees need to take an order over the phone. They need it broken down into digestible and easy to navigate steps.

Strategy

Pretty Straightforward

These components were designed to be easy to pop into our processes so that the user always knows where they are in the process and how much is left before they’re done.

Creativity

Usability and Accessibility First

Everything is designed with a focus on providing a great user experience, ensuring that the components are easy to use and accessible to all users.
